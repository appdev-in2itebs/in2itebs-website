# In2IT EBS Website — Features Plan (Plain-English Edition)

## Opening Note: Where This Comes From

This plan explains, in everyday language, every feature we recommend building for the new In2IT EBS website. It is written for business leaders and marketing colleagues — no technical background needed.

**Our single source of truth is the In2IT EBS "Corporate Capability" presentation, Deck 2 (May 2026).** Every fact, statistic, client name and service description in this plan is drawn from that deck. Where we suggest something the deck does not directly call for — an idea we believe will help the website win more business — we clearly mark it as our own recommendation.

We have kept the deck's own structure: the company is organised around **three pillars** (Platform Services; Advisory Services; Digital, Data & AI Services) plus a fourth section on how work is delivered. The website's menus, sections and headings follow that same shape so the site and the sales deck tell one consistent story.

### How to Read This Document — Legend

| Tag | Meaning |
|---|---|
| **(Deck)** | The feature is directly based on content or instructions in the May 2026 Corporate Capability deck. |
| **★ Additive** | Our own recommendation. The deck does not explicitly ask for it, but we believe it adds real business value. |

**Priority** tells you how important a feature is:
- **Must-have** — the site is not credible or complete without it.
- **Should-have** — strongly recommended; adds clear value soon after launch.
- **Nice-to-have** — a good future idea once the basics are working.

**Build effort** is a rough sense of how much work each feature is:
- **Small** — a few hours to a couple of days; mostly using things we already have.
- **Medium** — roughly half a week to a week of work; a new page or interactive piece.
- **Large** — a week or more; a genuinely new capability that needs careful building and ongoing care.

## Glossary

- **SAP** — A leading German software company whose business software runs the core operations (finance, supply chain, HR, etc.) of many of the world's largest organisations.
- **ERP (Enterprise Resource Planning)** — A single, joined-up software system that runs an organisation's main business functions together, so finance, procurement, manufacturing and HR all share the same up-to-date information.
- **S/4HANA** — SAP's latest-generation ERP system; the modern platform most large organisations are moving to.
- **RISE with SAP** — One route to the modern SAP system, aimed at larger, more complex organisations that want flexibility and deeper customisation. (Runs on a private, dedicated cloud.)
- **GROW with SAP** — The other main route, aimed at mid-sized or fast-moving organisations that want a quicker, standardised, lower-cost start. (Runs on a shared public cloud.)
- **PCE (Private Cloud Edition)** — A version of the SAP system hosted on a private, dedicated cloud for organisations needing heavy customisation or strict data isolation. In2IT EBS is a certified PCE partner.
- **AMS (Application Management Services)** — The ongoing "run and maintain" service after a system goes live — keeping it healthy, fixing issues and improving it over time.
- **SuccessFactors** — SAP's cloud software for human-resources management (recruiting, payroll, performance, learning, etc.).
- **Joule** — SAP's built-in AI assistant that lets people get answers and complete tasks across SAP systems using everyday language.
- **Concur** — SAP's software for managing travel and employee expenses.
- **Ariba** — SAP's software for purchasing and managing suppliers (procurement).
- **SAC (SAP Analytics Cloud)** — SAP's tool for dashboards, reporting, planning and forecasting.
- **BFSI** — Banking, Financial Services and Insurance; a common shorthand for the finance industry sector.
- **Greenfield / Brownfield migration** — Two ways of moving to the new SAP system: *greenfield* means a fresh start on a clean system; *brownfield* means upgrading the existing system in place, keeping its history.
- **ECC** — SAP's older-generation ERP system that organisations are migrating away from, onto S/4HANA.
- **HXM / HCM (Human Experience / Capital Management)** — The category of software for managing people and HR; SuccessFactors is SAP's product in this space.
- **NDA (Non-Disclosure Agreement)** — A confidentiality agreement; used here so detailed client case studies can be shared privately with serious prospects.
- **Hyperscaler** — A very large cloud-computing provider — Amazon Web Services (AWS), Microsoft Azure and Google Cloud — that hosts software and data at massive scale.
- **FastForward** — In2IT EBS's own branded delivery method, built on SAP's standard approach and sped up with ready-built tools to shorten project timelines by up to 30%.
